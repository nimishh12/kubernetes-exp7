# Experiment 07: Kubernetes Application Deployment

## Aim

To deploy and manage containerized applications using Kubernetes.

## Technologies Used

* Docker
* Kubernetes
* Minikube
* kubectl
* YAML

## Project Description

This project contains Kubernetes configuration files for deploying a containerized web application. The Deployment specifies the desired number of application replicas, while the Service exposes the application through a NodePort.

## Project Files

* `deployment.yaml` – Defines the application Deployment and replicas.
* `service.yaml` – Configures network access to the application.

## Objectives

* Deploy a containerized application.
* Expose the application using a Kubernetes Service.
* Scale the application by increasing the number of replicas.
* Understand Kubernetes self-healing.

## Status

Configuration files uploaded to GitHub. Cluster setup, deployment, scaling and self-healing verification are pending.
